# [PLACEHOLDER] Statut udruženja

Ovaj folder treba da sadrži zvanični PDF Statuta Udruženja građana "Staze Krajine".

**Šta uraditi:**
1. Dobiti potpisan/ovjeren PDF Statuta od vlasnika/predsjednika udruženja.
2. Preimenovati fajl u `statut.pdf` i staviti ga u ovaj folder (`public/dokumenti/statut.pdf`).
3. Link u footeru ("Statut (PDF)") će automatski raditi — ne treba mijenjati kod,
   putanja je već `/dokumenti/statut.pdf` (vidi `lib/site-config.ts`, polje `statuteUrl`).

Dok ovaj fajl ne postoji, link u footeru vodiće na 404 stranicu.
